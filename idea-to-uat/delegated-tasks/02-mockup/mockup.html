Flow (US-1/2/3/6)

  1. Ask → Jarvis judges: inline / delegate / decline.
  2. Delegate → one-line ack + a card (title, DoD, state). Chat free.
  3. Card updates live (step, running time). Brief and Cancel on the card.
  4. Finish → report message under the card (DoD ✅/❌), push to phone.
  5. Needs approval → card turns “waiting on you” with Approve / Deny.
  6. Error/empty: failed card says why; no tasks → chip hidden.

Call flow (US-4)

  1. Arsen asks for something that takes work → “noted: X” (one sentence).
  2. Quick questions are answered on the call as today.
  3. “What have you got?” → reads the list. “Drop the hotel one” → removed.
  4. Missing context → asks now, while he's on the line.
  5. Hang-up: one-sentence read-back; tasks start; call drop = same, started once.
  6. After-call report: one card, per task ✅/⏸/❌ + push.
Honesty check (US-5), any option. Before taking a task Jarvis checks can (tools + host up), knows enough (context), understands the goal. The ack says which is missing.
